gitfolio

A portfolio that builds itself from a GitHub profile. Put a username after the slash. Nothing to sign up for, nothing to configure.

Or go straight there: gitfolio.cpwillis.dev/<username> — for example /cpwillis or /torvalds.

What it does

  • Reads the profile at request time. Name, location, repositories, languages and stars come from the public GitHub API on every view. There is no database and nothing to update.
  • Screenshots the sites that are actually running. A repository with a working homepage gets a large card showing the live site. Everything else links to its source.
  • Keeps itself honest. A project whose site goes down drops back to a small card on its own, and returns when it comes back.

Themes

Add ?theme= to any page: space, cyberpunk, rainbow, mono, forest, sunset, nord, slate or paper. Left off, the accent is taken from the profile picture.

Run your own

It is one Worker and one HTML file, with no dependencies and no build step. Fork it, set your username, deploy. A fork serves only its own account unless you opt in to more.
